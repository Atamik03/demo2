# Аварии и характеристики оборудования

## Исправления

- Отказы оборудования регистрируются как критические события с привязкой к объекту. Повторные такты не создают дубликаты.
- Учитываются отдельные пределы HH/LL температуры и уровня; для нижних границ выбирается правильный порог, включая ноль. Значения действующих событий обновляются.
- В АРМ снятые неквитированные события остаются в нижней панели. Журнал содержит историю; список прокручивается и не ограничен пятью строками. Квитирование локально для открытого АРМ.
- Мощность отображается в кВт, тепловая нагрузка в МВт, КПД в процентах; API сохраняет единицы модели.
- Редактор насоса использует действительную расчётную характеристику: расход в м³/ч и перепад давления в барах. Исправлены масштабы начального открытия клапана и перепада давления теплообменника.
- В карточках насосов и теплообменников появились паспортные данные и ссылки на страницы исходных PDF.

## Источники и применённые значения

Документы из папки «ЭЛОУ-АВТ»:

- «9.1.3 Насосное оборудование.pdf»;
- «9.1.4 Теплообменное и холодильное оборудование.pdf».

Каталог содержит 156 позиций. Изменения параметров 51 объекта активной схемы перечислены в `equipment-corrections.json` (до/после и источники). Полная исходная схема сохранена в `backups/default.before-equipment-20260929-173540.json`.

Для однозначно сопоставленных насосов исправлены шаблонные расходы и добавлена паспортная частота вращения; для явно перечисленных групп теплообменников суммирована поверхность. Давление на выкиде не подставляется вместо перепада насоса. Расчётные температуры и давления не используются как аварийные уставки.

Для несопоставленных насосов с ошибочным старым значением 100 м³/с восстановлен смысл прежнего редактора: 100 кг/с при опорной плотности 850 кг/м³ (параметр `flow_basis`). Это приближение, не паспортная характеристика. Неоднозначные сокращения групп и прочие неподтверждённые паспортные значения не заменялись.

## Проверки

- 83 теста сервера: аварии, характеристики, колонны, симуляция, API и схемы.
- Три шага расчёта исправленной схемы из 162 объектов: состояние без NaN/Infinity.
- Сборка фронтенда успешна; ESLint без ошибок (91 предупреждение).
- Chromium: восемь событий в нижней панели, сохранение снятых событий до квитирования, квитирование всех и история; ошибок страницы нет. События подставлялись только в тестовую вкладку, без создания аварий в рабочей симуляции.
- Через работающий API проверены паспорт насоса и расход 450 м³/ч после перезапуска.
