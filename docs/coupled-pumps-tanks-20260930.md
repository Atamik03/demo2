# Насосы, общий коллектор, внешний теплоноситель и ёмкости — 30.09.2026

## Исправления

- `simulation_core/pump_network.py` решает баланс давления и массы для насосных сетей, питаемых внешними источниками. Общий коллектор больше не обрывает расчёт: насосы, регулирующие клапаны и каналы теплообменников входят в одну систему уравнений. Остановленный насос и закрытый клапан изолируют ветвь. При повторном пуске используется ненулевое начальное приближение.
- В этих сетях источник задаёт давление на всасывании; расход определяется характеристиками насосов и сопротивлением сети. Поле расхода источника не является жёстким ограничением подачи. В интерфейсе это обозначено. Внешние теплоносители без насосной сети сохраняют заданный расход.
- В АРМ администратор может открыть входящую стрелку и задать температуру и расход внешнего потока. Температура допускается от −50 до 1000 °C, как в серверной спецификации; старое ограничение ползунка 120 °C снято.
- Добавлена палитра `tank` / «Ёмкость», подключён существующий материальный баланс Tank. Графика — горизонтальный аппарат с эллиптическими днищами и внутренней шкалой уровня по приказу №251-П, приложение 5, рисунок 83 (PDF 111, печатная 110), требования п. 7.4.8.2. Высота шкалы учитывает высоту ёмкости; фиктивная водяная фаза для однофазной ёмкости не рисуется.
- Поверхность группы Т-6/1, Т-6/2, Т-7/1 (`hea_18`) исправлена с 200 на 1050 м²: 400 + 400 + 250. Источник: «9.1.4 Теплообменное и холодильное оборудование», таблица 18, PDF 2 / печатная 313.

## Что проверено

- Существующий набор: 338 тестов прошли. Добавлены три регрессионные проверки: частичное открытие и обороты; неодинаковые ветви с балансом массы; изменение температуры внешнего источника через весь движок до выходов теплообменника. После финальных изменений 18 целевых тестов прошли.
- На копии актуальной схемы: открытие трёх регуляторов 70 → 100% дало общий расход 411.494 → 491.647 кг/с; обороты всех трёх насосов 100 → 50% дали 245.820 кг/с. Это результаты модели с текущими параметрами, не паспортные рабочие расходы установки.
- На копии схемы с тестовыми внешними потоками 200 °C все шесть аппаратов первого блока передают тепло нефти. При уменьшении расхода нефти температура выхода меняется. Тестовые 200 °C в пользовательскую схему не записывались.
- TypeScript/Vite: сборка прошла, 857 модулей. Браузер: схема открывается без ошибок JavaScript; «Ёмкость» доступна в палитре и редакторе АРМ.
- Перед изменением площади сделана копия `backups/default-before-coupled-flow-20260930.json`. Сравнение после API-правки: изменён только `hea_18`; все 253 связи и расположение 216 объектов сохранены.

## Данные, которых нет для завершения настройки режима

По выбору пользователя входящие стрелки остаются внешними источниками. В сохранённой схеме большинство новых теплоносителей имеют 25 °C и 100 кг/с, нефть — 28 °C. При таких входах физически получается охлаждение нефти, а не подогрев.

Проверены «3. Описание технологического процесса» и «9.1.4 Теплообменное и холодильное оборудование» из папки ЭЛОУ-АВТ, а также документы проекта:

- Раздел 3.2 (PDF 2–3 / печатные 27–28): состав горячих потоков, маршруты и предел температуры нефти после блока ≤140 °C. Нет штатных температур и расходов каждого внешнего теплоносителя.
- PDF 12–13 / печатные 37–38: маршруты трёх ц.о. К-2 и минимальные аварийные расходы 20 м³/ч для 2 и 3 ц.о. Эти пороги не являются рабочими расходами.
- PDF 16 / печатная 41: рабочий диапазон 180–220 °C для К-12/2,3 при включённом блоке демеркаптанизации. Это не универсальная температура всех потоков и не точное начальное значение на входе Т-1/3.
- PDF 21 / печатная 46: маршруты двух потоков мазута через предыдущие ступени теплообмена. Температура низа К-2 (предельная 350 °C) не равна температуре после этих ступеней.
- Паспортная таблица 18 содержит **расчётные температуры аппаратов**, а не рабочие температуры потоков. В ней нет рабочих массовых расходов.
- Для Т-6/1, Т-6/2, Т-7/1 по документации теплоноситель — фр. **300–350 °C**; пользовательская подпись входа сейчас «300–500».

Рабочие начальные значения внешних потоков не выдумывались и остаются без изменения. Для их назначения по документации нужна таблица норм технологического режима (соответствующий раздел регламента) или режимная карта с температурами и расходами в выбранных точках границы.

## Дополнение: изменение температуры через API

При повторной проверке обнаружено рассогласование: у source_192 сохранено 180 °C, а в работающей модели оставалось 25 °C. `/equipment/params` обновлял сохранённый узел и объект оборудования, но у внешнего источника нет объекта оборудования; его отдельная копия в `_node_map` не обновлялась. Исправлено обновление параметров расчётного узла без сброса состояния установки. Добавлен регрессионный тест с раздельными копиями схемы, вызовом обработчика API и проверкой температуры, расхода и теплопередачи. 12 целевых тестов прошли.

После перезапуска и повторного применения сохранённых пользователем 180 °C через API: source_192 = 180 °C, нефть на группе Т-1: 28 → 111.60 °C. На следующей группе Т-2/Т-3: 111.60 → 66.95 °C, поскольку её внешний теплоноситель source_193 по-прежнему задан 25 °C. Значения остальных внешних источников не изменены.
