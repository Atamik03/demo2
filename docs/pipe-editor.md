# Редактирование трубопроводов и КИП

Редактор доступен администратору в обычной мнемосхеме и в режиме АРМ.

- Клик по трубе выбирает её без изменения трассы.
- Перетаскивание горизонтального участка сдвигает его вверх/вниз, вертикального — влево/вправо. Штуцеры остаются на аппаратах.
- Двойной ЛКМ по трубе начинает отвод. Затем нажмите входной штуцер аппарата.
- Двойной ПКМ по трубе начинает входящую ветвь. Затем нажмите выходной штуцер источника ветви.
- На аппарате с несколькими штуцерами нужно выбрать конкретный штуцер. Esc отменяет подключение.
- Врезка создаёт настоящий тройник в графе процесса. Точки трассы и привязки КИП сохраняются. Ctrl+Z отменяет жест целиком.
- Элемент палитры «Продолжение линии →» обозначает выход за границу текущей схемы. Подключите к нему трубу и двойным щелчком задайте назначение, например «На К-9 · лист 4». Это подписанная граница отбора; текст сам по себе не соединяет два участка модели.

## Обозначение КИП

Используется существующий мнемоэлемент `ins` из `src/mnemo/symbols.tsx`: прямоугольник с позиционным тегом, измеренным значением и единицей измерения. Такое представление описано в приказе № 251-П, раздел 7.4.2, страница 32 PDF из папки «ЭЛОУ-АВТ». Привязка к трубе проходит через центр элемента. Позиционное обозначение редактируется отдельно от наименования в инспекторе.

## Исправления реакции колонн

- API передавал каждой колонне общий уровень первой колонны. Теперь передаётся уровень конкретного аппарата; аналогично исправлен уровень ЭЛОУ.
- Колонна с одним входом ошибочно считалась сквозным разветвлением гидравлической сети. Теперь она, как и колонна с несколькими входами, имеет собственный запас жидкости.
- Закрытая задвижка могла получить ненулевой поток из сглаженного гидравлического расчёта. Закрытие теперь сохраняется при применении результата расчёта.
- Ограничение отвода учитывает закрытые задвижки и остановленные насосы; ограничение продуктовой линии не переносится напрямую на подачу через запас жидкости колонны.
