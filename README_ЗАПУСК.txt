Быстрый запуск на Windows:
1. Установите Python 3.11+ и Node.js 18+.
2. Запустите START_ALL.bat.
3. Откройте http://localhost:5173.

Первый запуск установит зависимости и создаст локальное окружение.
Собранная версия фронтенда также находится в elou_avt_web\dist.
